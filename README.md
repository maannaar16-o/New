# 💪 بطل — تطبيق تغذية فارس

تطبيق ويب (PWA) بالعربية لمساعدة أم فارس على متابعة تغذيته اليومية.

فارس بطل عمره ١٢ سنة، والتطبيق يساعد والدته على:

- 🍽️ **تسجيل وجبات اليوم** (فطار / غدا / عشا / سناك) بمقادير منزلية سهلة (ملعقة، كوب، ربع رغيف...) أو بالجرامات
- 📊 **تحويل الوجبات تلقائيًا للعناصر الغذائية**: سعرات، بروتين، ألياف، كالسيوم، حديد، زنك، فيتامينات أ / ج / د
- ✅ **تقييم اليوم**: هل تغذية فارس جيدة أم يحتاج المزيد من عنصر معين — مع اقتراح أطعمة تعوض الناقص
- 💧 **عدّاد شرب الماء** — مهم جدًا للوقاية من الإمساك
- 📅 **سجل أسبوعي** يصلح لعرضه على طبيب فارس أو أخصائي التغذية
- 📚 **معلومات غذائية مبسطة** تشمل نصائح خاصة بأطفال الشلل الدماغي (صحة العظام، قوام الطعام، الألياف والسوائل)
- ⚙️ **أهداف قابلة للتعديل** حسب توصية الطبيب
- ❤️ رسائل تحفيزية يومية لأم البطل ولفارس

البيانات كلها محفوظة على هاتف المستخدم فقط (localStorage) — لا سيرفر ولا حسابات ولا إنترنت مطلوب بعد أول فتح.

> ⚠️ التطبيق أداة مساعدة للأسرة، والقيم الافتراضية استرشادية — لا يغني عن متابعة الطبيب أو أخصائي التغذية.

## 🚀 التشغيل والنشر

### تجربة محلية

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

### النشر على GitHub Pages (مجاني)

1. ادمج هذا الفرع في `main`
2. من إعدادات المستودع على GitHub: **Settings ← Pages ← Source: GitHub Actions**
3. مع كل دفعة إلى `main` سيُنشر التطبيق تلقائيًا عبر `.github/workflows/deploy-pages.yml`
4. الرابط سيكون بالشكل: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

### إضافة التطبيق لهاتف الأم 📱

1. افتحي الرابط من متصفح الهاتف (Chrome أو Safari)
2. من قائمة المتصفح اختاري **«إضافة إلى الشاشة الرئيسية» / Add to Home Screen**
3. ستظهر أيقونة «بطل» على الشاشة الرئيسية ويعمل التطبيق كتطبيق عادي حتى بدون إنترنت

## 🤖 نسخة أندرويد APK

يوجد أيضًا تطبيق أندرويد أصلي (غلاف WebView يحمل نفس التطبيق مدمجًا بداخله — يعمل بلا إنترنت نهائيًا وبدون أي صلاحيات):

1. حمّل ملف **`batal-faris.apk`** من صفحة [Releases](../../releases/tag/apk)
2. افتح الملف على الهاتف واسمح بـ«التثبيت من مصادر غير معروفة» عندما يسألك
3. ستظهر أيقونة «بطل» بين تطبيقات الهاتف

يُبنى الـ APK تلقائيًا عبر `.github/workflows/build-apk.yml` مع كل تعديل على التطبيق، ويُرفع لنفس صفحة الـ Release. مشروع الأندرويد في مجلد `android/` وينسخ ملفات الويب من جذر المستودع عند البناء، فالنسختان (الويب والـ APK) متطابقتان دائمًا.

> **توقيع الـ APK**: مفتاح التوقيع الثابت محفوظ مشفّرًا في `android/app/batal.keystore.enc`. أضف سرًّا واحدًا باسم `BATAL_KEY_PASSPHRASE` (كلمة فك التشفير) في إعدادات المستودع (Settings ← Secrets and variables ← Actions) وستحمل كل النسخ نفس التوقيع وتقبل التحديث فوق بعضها. بدونه يولّد كل بناء مفتاحًا مؤقتًا، وعندها يجب حذف التطبيق القديم قبل تثبيت نسخة أحدث.

## 🗂️ بنية المشروع

| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الشاشات الست (رئيسية، وجبات، تقييم، أسبوع، معلومات، إعدادات) |
| `css/style.css` | التصميم — عربي RTL، خط كبير، وضع ليلي تلقائي |
| `js/foods.js` | قاعدة بيانات ~٩٠ صنف طعام مصري/عربي بقيمها الغذائية لكل ١٠٠ جم ووحداتها المنزلية |
| `js/app.js` | منطق التطبيق: الحساب، التقييم، الاقتراحات، التخزين |
| `manifest.webmanifest` + `sw.js` | ملفات الـ PWA للعمل دون إنترنت والإضافة للشاشة الرئيسية |
